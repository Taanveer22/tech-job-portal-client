# Tech Job Portal Client

A frontend client for the **Tech Job Portal** application, built with **React.js** and integrated with a secure backend. It provides a modern UI for job seekers and employers to interact with job listings, applications, and dashboards.

## 🚀 Features

- **Authentication**: Login/logout with JWT and cookies
- **Private Routes**: Protected pages with redirect setup
- **Job Listings**: Browse, search, and filter jobs dynamically
- **Applications**: Apply to jobs, view status live, and manage applications
- **CRUD Operations**: Create, update, and delete jobs and applications
- **Reviews & Counts**: HR can view applications count and reviews
- **Custom Axios Hook**: Centralized API calls with credentials included
- **Optimized Deployment**: Firebase hosting with CORS/JWT fixes
- **Responsive UI**: Banner, hot jobs, framer motion animations

## 🛠 Tech Stack

- **Frontend Framework**: React.js
- **UI Styling**: TailwindCSS + Framer Motion
- **Routing**: React Router
- **State Management**: React Hooks & Context
- **HTTP Client**: Axios (custom hook)
- **Hosting**: Firebase Hosting
- **API Integration**: REST APIs with backend server
